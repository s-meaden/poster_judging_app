# poster_judging_app

1. Download R to your local device.
2. Download and install Rstudio to your local device.

3. Copy paste the dependencies.R to your local device.
4. Open depdendecies.R and run the code. Check for error messages in the terminal.

5. Repeat this process for the app- copy and paste script to a new file. Ensure it's saved as an .R script so RStudio knows it's an app.
6. Open this script: poster_judging_app.R
7. In the top right - click 'Run App'.
8. The app should open. Use the Browse file button to upload your data.
9. The leaderboard should automatically update ranked on average poster score and career stage.

NB. The original_scoring.R script should not be necessary, but it is a backup for running the calculation outside of the app.
